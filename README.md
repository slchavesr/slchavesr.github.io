# MATH 1001 — Final Exam Practice Center (revised)

Static website for GitHub Pages. Upload the files at the ZIP root to the course directory; open `index.html`.

## Practice
- Six subjects: Sets, Counting, Probability, Statistics, Units, Finance.
- 30-question unlimited-time exam: Sets 5, Counting 5, Probability 5, Statistics 6, Units 4, Finance 5.
- Topic generators include random numbers, contexts and varied assessed methods.
- Check Answer, Hint, Show Solution, Generate New.
- Exam solutions and score appear only after submission.
- Interactive 8-region Venn diagrams, histograms, bar charts, pie charts and scatter diagrams.
- Scatter diagram construction also assesses means, sample standard deviations, covariance and Pearson r.
- Separate regression question asks for slope, intercept and prediction.
- Revised comprehensive formula sheet avoids binomial coefficient notation and uses C(n,r).

## Requirements
No backend or login is needed. MathJax is loaded from a CDN, so internet access is required for formatted mathematical notation.

## Notes
- Practice diagrams use an interactive coordinate grid or bar/sector controls; students can use the keyboard for numerical fields.
- Numerical answers accept a tolerance of about 0.005 to support two-decimal rounding.
- In the full exam, each multi-part question is counted as one question for scoring.
- Original Exam 3 generator files are included as archived reference only and are not loaded by the revised website.
