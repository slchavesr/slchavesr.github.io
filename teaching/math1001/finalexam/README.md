# MATH 1001 — Final Exam Practice Center

Open `index.html` to practice by topic. Open `exam.html` for a randomized 30-question untimed practice final. Upload all website files together to the same GitHub Pages directory.

## Full exam allocation
Sets 5; Counting 5; Probability 5; Statistics 6 (at least two interactive diagram questions); Units 4; Finance 5. Every generated question is selected from the question banks and gets newly randomized data.

## Features
Topic practice: check answer, hint, worked solution, generate new question.
Exam: 30 questions, no time limit, regenerate, print, submit, grade and review solutions. Interactive diagrams include histogram, bar chart, pie chart, scatter plot, and selectable Venn regions.

## Notes
No login, backend, or stored scores. MathJax requires an internet connection for mathematical typesetting. Questions are modeled on Exams 1, 2 and 3 supplied by the instructor. The original Exam 3 scripts are preserved as `exam3_original.js` and `exam3_exam_original.js` for reference, but are not loaded.
