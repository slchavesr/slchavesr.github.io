# MATH 1190 Exam 3 Practice Center — Version 4

Static website for GitHub Pages. Upload `index.html`, `app.js`, `advanced.js`, and `style.css` together to `teaching/1190/`.

New in Version 4:
- Five labeled graph points with 15 multiple-choice sign selections for f, f', f''.
- Coordinate-table answers for all absolute maxima and minima, with add/remove rows and classifications.
- Multi-part cubic curve analysis including intervals, concavity, inflection, and classified critical points.
- Varied derivative graphs: quadratic, cubic, quartic, sinusoidal, and linear.
- Formula-based sketching with a coordinate table, an editable smooth interpolated curve, and the correct graph for comparison.
- Original practice-exam mode, related rates, optimization, L'Hôpital and theorem generators retained.

Important: The advanced multipart practice modes are available in topic practice. Practice exam retains its prior question formats and graph investigation. The interpolated student curve is not automatically graded for calculus correctness; entered feature-point coordinates and types are checked. Automatic checking uses numerical tolerances for coordinates and text normalization for intervals.

MathJax and optional MathLive/Compute Engine require an internet connection. The core practice controls work without these external libraries, though mathematical notation may appear unrendered.
