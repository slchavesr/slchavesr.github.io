# MATH 1190 Exam 3 Practice Center — Version 3.2

Upload `index.html`, `app.js`, and `style.css` to `teaching/1190/` in your GitHub Pages repository. The website has 1001-style topic buttons and separate Practice Exam, Graph Investigation, and Guide views.

After updating GitHub Pages, hard-refresh with Ctrl+Shift+R.

The advanced equation editor and symbolic engine load optionally; text entry is always available. Automatic checking is formative, especially for interval and graph questions.
